# AI Touch Bar 0.2.3

也许，现在才是 Touch Bar 的「最佳赏味期限」。

本次更新让 Kimi 任务可以手动选择，并修复额度已恢复、进度条却仍被旧月限额记录遮挡的问题。原生菜单栏 App，仍然不依赖 BetterTouchTool。

## 更新内容

- **Kimi 三种监看方式**：自动监看唯一活跃任务、指定一个任务、不监看。多个任务并行时，手动选择按任务 ID 固定，不会被其他任务顶替。
- 切换选择时立即清除旧状态，并丢弃旧请求的迟到响应。任务暂时缺失时保留选择、隐藏状态；服务未连接不再与额度耗尽混淆。
- 修正 Kimi 月限额记录的秒／毫秒时间处理，支持用户明确记录一次本机额度恢复确认。新的月限额错误仍会显示红色 `WAIT!`，不从小时／周额度猜测月额度是否恢复。
- 操作框增加 Kimi 下拉框、刷新按钮和状态说明；保留现有像素动画、额度常驻、图钉收起／展开、关闭窗口但不退出的行为。
- 更新 README、隐私说明和开发交接，区分离线验证、界面验证与尚未完成的真实任务联调。

## 下载与安装

下载本页附件：

- `AI-Touch-Bar-v0.2.3-macos-arm64.zip`
- `SHA256SUMS.txt`

将两者放在同一目录，核对下载完整性：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

升级前，从菜单栏图钉选择“退出”旧版。解压后，将 `AI Touch Bar.app` 拖入“应用程序”；打开操作框后点击“显示 Touch Bar”。无需退出 Codex 或 Kimi，也不会停止它们的任务。

安装包仅支持 **Apple Silicon（arm64）**，构建目标 macOS 13+，验证环境为 macOS 15.8。需要可运行的 `/usr/bin/python3`（Python 3.9+）及系统 `curl`；未捆绑 Python 运行时。Intel 用户可从源码构建，尚未实机验证。

**实验性预发布版，仅 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。** 首次打开的安全提示见 [README](https://github.com/tigerrrr2020/ai-touchbar/blob/v0.2.3/README.md#下载与使用)。请核对来源与校验值，不要关闭系统全局安全检查。

## 验证与已知限制

发布构建已通过 10 项状态桥接测试、44 项上游模块测试、bridge 生命周期检查、状态／额度自检、原生 AppKit 自检、签名及 ZIP 完整性检查。离线样例不调用真实模型或读取真实凭据。

已检查安装版的下拉选项、停用隐藏、刷新保留选择及两组模拟动画布局。**真实 Kimi 多任务切换、审批、完成和断连恢复仍待联调**；模拟动画与单元测试不是该流程的实测证明。

Codex 仍需手动选择任务，不会自动跟随当前页面，真实审批状态识别尚不完整。Kimi 监看依赖可用的本地服务，不支持多 daemon 聚合；身份或完整列表无法确认时隐藏状态。Kimi 月额度接口字段仍缺失，恢复确认只能在用户已确认额度恢复后执行。

Touch Bar 桥接使用私有系统接口，兼容性可能随 macOS 改变。没有开机自启、听写、Siri 替换或自动审批。

实时额度会读取本机已登录客户端；Kimi OAuth 可能刷新并写回本机凭据。完整边界见 [隐私说明](https://github.com/tigerrrr2020/ai-touchbar/blob/v0.2.3/docs/PRIVACY.md)与 [开发交接](https://github.com/tigerrrr2020/ai-touchbar/blob/v0.2.3/docs/HANDOFF.md)。本次保留 v0.2.1 发布及附件，不覆盖旧包。
